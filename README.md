# Exploring Basic Linux Commands: My Learning Journey

## Project Overview

This project documents my beginner learning journey exploring essential Linux commands using Ubuntu 24.04 LTS through Windows Subsystem for Linux (WSL).

The goal was to develop practical familiarity with Linux terminal operations and understand how these commands support everyday system administration, cloud computing, and DevOps activities.

## What I Practised

- **Filesystem navigation:** `pwd`, `ls`, `cd`, `mkdir`, `rm`
- **File management:** `touch`, `echo`, `cat`, `cp`, `mv`, `grep`
- **Users and permissions:** `whoami`, `id`, `sudo`, `usermod`, `chmod`, `chown`
- **Process management:** `ps`, `top`, `kill`
- **Package management:** `apt`, with research into `yum` and `dnf`

## Learning Environment

- Operating system: Ubuntu 24.04 LTS
- Environment: Windows Subsystem for Linux (WSL)
- Practice type: Independent beginner exercise

## Key Takeaway

This exercise helped me become more comfortable working in the Linux terminal and understand the purpose of commands used to navigate files, manage permissions, inspect processes, and manage software packages.

This is an ongoing learning journey as I build practical foundations for cloud computing and DevOps.
