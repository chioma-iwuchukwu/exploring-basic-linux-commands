# Basic Linux Commands – Practice Notes

**Operating System:** Ubuntu 24.04 LTS  
**Environment:** Windows Subsystem for Linux (WSL)  
**Project:** Beginner Linux command practice

## 1. Filesystem Navigation
- `pwd` – Displays the current working directory.
- `ls` – Lists files and directories.
- `cd` – Changes the current directory.
- `mkdir` – Creates a directory.
- `rm` – Removes files.

## 2. File Management
- `touch` – Creates an empty file.
- `echo` – Displays text or writes text into a file.
- `cat` – Displays file contents.
- `cp` – Copies files.
- `mv` – Moves or renames files.
- `grep` – Searches for matching text in files.

## 3. Users and Permissions
- `whoami` – Displays the current username.
- `id` – Displays user and group information.
- `sudo` – Runs commands with administrator privileges.
- `chmod` – Changes file permissions.
- `chown` – Changes file ownership.
- `usermod` – Modifies an existing user account.

## 4. Process Management
- `ps` – Displays running processes.
- `top` – Shows processes and system activity in real time.
- `kill` – Sends a signal to a process, commonly to stop it.

## 5. Package Management
- `apt` – Manages software packages on Ubuntu and Debian.
- `yum` – Package manager used by older Red Hat-based distributions.
- `dnf` – Package manager used by Fedora and newer Red Hat-based distributions.

**Practice note:** I used APT on Ubuntu. YUM and DNF are included to explain their roles in other Linux distributions; I did not execute them on Ubuntu.

## Learning Environment

I created a practice directory called `linux-practice`, created and edited a text file, tested file permissions, created a temporary user account, and explored running processes.

This was an independent beginner learning exercise using Ubuntu 24.04 through WSL.
